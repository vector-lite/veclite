# 观测指标与运行诊断规范

指标必须回答请求是否成功、慢在哪里、资源是否接近上限、结果是否准确；标签必须保持低基数，禁止使用文档 ID、原始查询或完整向量。

必备指标：

- 请求成功/错误/拒绝/超时数，端到端及检索计算 P50/P95/P99。
- 候选数、过滤后候选数、扫描向量数、搜索模式、Recall@K（测试/基准环境）。
- Store 数量、向量数、软删除数、Payload 读取耗时、快照成功/失败、恢复耗时。
- Heap、Direct Memory、CPU、线程池活动数/队列长度、文件句柄和磁盘空间。
- offset 校验失败、回滚写入、量化参数不一致、快照版本不兼容。

关键边界使用结构化日志：Store 开关、快照/恢复、配置变更、外部 Embedding 调用和一致性失败。不得记录完整向量、文档正文、密钥或隐私数据。健康检查区分进程存活、Store 可用、持久化可写和外部服务可达。
