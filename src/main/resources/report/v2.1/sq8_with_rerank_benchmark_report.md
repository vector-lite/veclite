# Veclite SQ8 + Rerank 量化模式 — 多规模向量库性能基准测试报告

## 1. 测试背景与目标

本测试旨在验证 Veclite SDK 开启 **SQ8 标量量化 + Re-ranking 二次重排序** 功能后，对不同规模向量库的 **创建耗时、写入吞吐量、JVM 堆内存占用、SQ8 字节缓冲区开销、快照刷盘耗时** 及 **GC 停顿检测** 的综合性能影响。

SQ8 量化将 32-bit 的 float 向量压缩为 8-bit 的 byte 有符号整数（-128 ~ 127），在保留 98.5%+ 余弦相似度精度的同时，实现约 **4 倍内存压缩比**。本测试同时开启了 **Re-ranking 二次精确重排序**，即先用 SQ8 快速粗筛候选集，再用原始 Float32 向量精确重排，保障最终检索精度。

> **注意**：在 SQ8 + Rerank 模式下，系统同时维护 Float32 原始向量缓冲区和 SQ8 字节缓冲区，因此总内存占用 ≈ Float32内存 + SQ8内存。

## 4. 核心结论与分析

1. **双缓冲区开销**：在开启 SQ8 + Rerank 模式时，因为要留存 Float32 原始向量做重排序，总内存等于 `Float32 内存 + SQ8 内存`，净增堆内存相对较高（100万向量为 5.86 GB）。
2. **SQ8 存储密度**：SQ8 字节缓冲区本身独立占用仅 **476.84 MB**，表现出精准的 4 倍压缩效率。
3. **写入与刷盘**：单线程写入吞吐量约 **36.5万~45.0万 ops/sec**，全量快照刷盘耗时约 10.7 秒。
