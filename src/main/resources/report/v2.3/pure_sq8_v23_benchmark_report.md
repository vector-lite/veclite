# Veclite V2.3 极致空间压缩与零 GC 堆外化 — 性能基准测试报告

## 1. 测试背景与架构演进说明

本报告针对 **Veclite V2.3 最新架构** 进行全量基准测试，核心对比 V2.2 版本验证以下 3 大模块的优化效果：

1. **OffHeapSQ8Buffer (堆外内存 SQ8 缓冲区)**：将 SQ8 字节数组分配在 OS Direct Memory 堆外空间，JVM 堆内零 GC 扫描开销。
2. **MMapPayloadStorage (Payload 磁盘 MMap 延迟加载)**：文档 Text 和 Metadata JSON 格式存储在磁盘 MMap 文件中，向量检索阶段零 Payload 对象加载，按 Top-K 最终结果延迟反查。
3. **IntLongIdIndex (数值化 ID 字典与轻量映射)**：采用开放寻址平铺 long[] 数组取代 ConcurrentHashMap 节点与装箱对象。
